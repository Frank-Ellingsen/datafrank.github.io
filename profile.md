# 05. CONTROLLER WORKFLOW

# From Data to Actionable Control

## CONTROL → EXPLAIN → FORECAST → ACT

### CONTROL
**Are the numbers reliable?**

Reconcile actuals, validate data quality and identify exceptions.

### EXPLAIN
**What caused the variance?**

Identify financial drivers, operational causes and material deviations.

### FORECAST
**Where are we heading?**

Update forecasts, EAC/ETC and scenarios using current performance.

### ACT
**What requires management attention?**

Translate financial insight into decisions, actions and follow-up.
